# Ensayo Audio para Android

App Android con 28 enlaces únicos precargados. Permite seleccionar pistas,
extraer audio MP3 y generar una copia con cambio de tono entre -6 y +6 semitonos.

## Compilar

1. Abrir esta carpeta en Android Studio.
2. Esperar la sincronización de Gradle.
3. Elegir **Build > Build APK(s)**.

El APK queda en `app/build/outputs/apk/debug/app-debug.apk`.

Usar únicamente con contenido propio o con permiso para descargarlo.
